# Contributing · Contribuições

## English

Use Node.js 22 or newer. Run `npm test`, `npm run examples` and the browser before proposing a change. Keep domain behavior independent of the interface and explain changed assumptions. Add regression tests for real behavior, including rejected inputs and numerical boundaries. Update both English and Portuguese documentation and interface text.

Public work must be independently reviewable. Submit synthetic examples and generic interfaces only. Do not copy private implementation details, unpublished protocols, credentials or participant records. A future physical adapter requires explicit interface documentation and a separately documented validation plan.

Describe the problem, before/after behavior, relevant tests and remaining limitations in the pull request. Keep changes focused. Respect participant autonomy and accessibility preferences; do not infer a person's needs from a diagnosis. Contributions use the repository's MIT license.

## Português

Use Node.js 22 ou mais recente. Execute `npm test`, `npm run examples` e o navegador antes de propor alterações. Mantenha o comportamento de domínio independente da interface e explique mudanças nas hipóteses. Acrescente testes de regressão para comportamentos reais, incluindo entradas rejeitadas e limites numéricos. Atualize documentação e interface em português e inglês.

O trabalho público deve ser revisável de forma independente. Envie apenas exemplos sintéticos e interfaces genéricas. Não copie detalhes de implementações privadas, protocolos não publicados, credenciais ou registros de participantes. Um futuro adaptador físico exige documentação explícita da interface e plano de validação separado.

Descreva problema, comportamento anterior e posterior, testes relevantes e limitações restantes na proposta de alteração. Mantenha o escopo definido. Respeite a autonomia e as preferências de acessibilidade; não deduza necessidades de uma pessoa a partir de um diagnóstico. As contribuições seguem a licença MIT do repositório.
