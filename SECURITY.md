# Security and privacy · Segurança e privacidade

## English

The workbench has no accounts, application backend, analytics or automatic report uploads. It fetches static application files and synthetic examples from its hosting provider. The host receives ordinary web requests. Scenario analysis runs in the browser; only the language preference is stored automatically. Exports are explicit local downloads. Source JSON and earlier downloads remain under the user's control.

Use synthetic data in public examples, issues and screenshots. Never include credentials, private source, unpublished device configurations, identifying participant records or confidential operational data. Public companion code must remain independent of any private implementation.

Report a suspected vulnerability to **gabrieldemetrioslafis@usp.br**, with a minimal synthetic reproduction. Avoid public disclosure of sensitive details while a report is being assessed. Version 0.1.x is the initial supported line; response times are not guaranteed.

## Português

A bancada não possui contas, servidor de aplicação, métricas de uso ou envio automático de relatórios. Ela busca arquivos estáticos e exemplos sintéticos no provedor de hospedagem, que recebe requisições comuns de acesso. A análise ocorre no navegador; apenas a preferência de idioma é armazenada automaticamente. As exportações são downloads locais explícitos. O JSON de origem e downloads anteriores permanecem sob controle do usuário.

Use dados sintéticos em exemplos públicos, relatos e capturas de tela. Não inclua credenciais, código privado, configurações não publicadas de dispositivos, registros que identifiquem participantes ou dados operacionais confidenciais. O código público complementar deve permanecer independente de qualquer implementação privada.

Relate suspeitas de vulnerabilidade a **gabrieldemetrioslafis@usp.br**, com reprodução sintética mínima. Evite expor detalhes sensíveis publicamente durante a avaliação. A versão 0.1.x é a linha inicial de suporte; não há prazo de resposta garantido.
